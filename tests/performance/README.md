# 로딩 성능 회귀 테스트

```sh
npm run test:performance
```

고정 API 응답과 **프로덕션 빌드**를 사용한다. 4173 포트가 비어 있어야 하며 운영 서버에는 요청하지 않는다. 기존 community fixture를 공유한다.

검증 대상:

- 390/900/901/1440px 로그인 hero 요청 및 화면 확대 시 정상 로드
- 타자 메인·일상·문장 설정/일상 편집의 Monaco 미로딩
- Java/JS 연습과 코드 문장 편집의 로컬 Worker, 실제 입력, 언어 전환
- 기본 서식·목록·안전한 링크의 정적 렌더링과 미지원 서식 fallback
- 복합 블록 뒤 번호 목록의 순서 보존, 코드 청크 실패 안내
- 로컬 기본 프로필의 잘못된 API 요청 방지
- 프로필 1회 조회, 응답 전 로그아웃, 401 재발급, 계정 전환 경합
- 지연·실패한 아바타가 홈 멤버 표시와 다음 배치를 막지 않음
- visibility 변경 시 통계 폴링 중단과 복귀 갱신

`visibility.spec.ts`는 DOM visibility 상태를 제어하는 결정적 회귀 테스트다. 실제 운영 브라우저의 탭 전환 성능이나 hidden 상태 재현을 대신하지 않는다. 실제 headed 브라우저 검증은 별도 CDP 세션에서 수행하며, 구현 결과 보고서에 증거를 기록한다.

로드 자산의 gzip 용량과 LCP 비교는 고정된 CPU/네트워크/캐시 조건의 별도 측정으로 수행한다. 이 테스트의 실행 시간은 성능 점수로 사용하지 않는다.
