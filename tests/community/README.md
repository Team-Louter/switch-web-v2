# 커뮤니티 목록 회귀 테스트

실제 Chromium에서 목록 조회와 화면 이동을 검증합니다. API 응답은 테스트 fixture로 대체하며 운영 서버에는 요청하지 않습니다.

```sh
npm ci
npx playwright install chromium
npm run test:community
```

테스트 실행 시 `127.0.0.1:4173`에 Vite 서버를 자동으로 시작합니다. 해당 포트는 비어 있어야 합니다. 실패한 테스트의 화면과 trace는 `test-results/`에 저장됩니다.

검증 범위는 중복 요청, 최초 로딩과 실패·재시도, 목록 복귀와 스크롤 복원, 캐시 만료, 로그아웃, 게시글·반응·댓글 변경 후 갱신, 지연된 조회 응답과 변경 요청의 경합입니다.
