# 이전 타자 연습 결과 조회 API 연결

## 사용자 프롬프트

이전 타자 연습 결과 조회를 문장 관리 API 작업과 분리하여 별도 커밋으로 구성한다.

## 기존 상태

- 타자 연습 진입 화면의 이전 타수, 정확도, 소요 시간은 고정 문자열로 표시되었다.
- 서버의 이전 결과 응답을 표현하거나 조회하는 타입과 API 함수가 없었다.
- 요약 카드의 값 타입이 문자열로 고정되어 숫자 응답을 그대로 전달할 수 없었다.

## 작업 내용

- 이전 결과의 식별자, 정확도, 소요 시간, 평균 타수를 표현하는 `TypingResult` 타입을 추가했다.
- `/typing/results/previous`를 호출하는 `getPreviousResult` 함수를 entities 레이어에 추가했다.
- 페이지가 처음 렌더링될 때 이전 결과를 한 번 조회해 상태에 저장하도록 연결했다.
- 조회 결과의 평균 타수, 정확도, 소요 시간을 해당 요약 카드에 전달했다.
- API 숫자 값을 받을 수 있도록 `SummaryCard`의 `value` 타입을 숫자로 변경하고 나머지 숫자 카드도 같은 타입으로 맞췄다.

## 결과

- 타자 연습 진입 화면에서 고정 예시 대신 사용자의 직전 연습 결과가 표시된다.
- 결과 상태를 갱신해도 조회 effect가 다시 실행되지 않아 반복 API 요청이 발생하지 않는다.
- 요약 카드가 서버 응답의 숫자 데이터를 별도 문자열 변환 없이 표시한다.
