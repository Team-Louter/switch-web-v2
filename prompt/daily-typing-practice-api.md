# 일상 영어 타자 연습 문장 API 연결

## 사용자 프롬프트

현재 개발한 변경을 코드와 파일 단위로 나누고, 일상 영어 타자 연습 문장 API 연결을 별도 커밋으로 구성한다.

## 기존 상태

- 일상 영어 연습 화면은 현재 문장과 주변 문장을 하드코딩해서 표시했다.
- 한 문장을 입력한 뒤 다음 연습 문장으로 넘어가는 흐름이 연결되지 않았다.
- 입력값은 일반 input으로 표시되어 기준 문장과 다른 글자를 즉시 구분할 수 없었다.

## 작업 내용

- 화면 진입 시 `DAILY` 유형의 연습 문장 목록을 조회하도록 연결했다.
- 조회 목록과 현재 인덱스를 사용해 이전, 현재, 다음 문장을 표시했다.
- 현재 문장 길이만큼 입력한 뒤 Enter를 누르면 다음 문장으로 이동하고 입력값을 초기화하도록 했다.
- 마지막 문장을 완료하면 타자 연습 진입 화면으로 이동하도록 했다.
- 실제 input의 글자는 투명하게 유지하면서 별도 문자 레이어에서 정답 글자와 오답 글자를 구분해 표시했다.
- 기존 시간, 타수와 정확도 계산이 API에서 받은 현재 문장을 기준으로 동작하도록 변경했다.

## 결과

- 일상 영어 연습 화면이 서버에서 제공하는 문장을 순서대로 사용한다.
- 사용자는 이전 문장과 다음 문장을 함께 확인하면서 현재 문장을 입력할 수 있다.
- 잘못 입력한 글자가 즉시 구분되고, 문장 완료 시 다음 문제 또는 연습 진입 화면으로 자연스럽게 이동한다.
