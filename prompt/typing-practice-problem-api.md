# 타자 연습용 문장 목록 조회 API 추가

## 사용자 프롬프트

현재 개발한 변경을 코드와 파일 단위로 나누고, 연습용 문장 목록 조회 API를 별도 커밋으로 구성한다.

## 기존 상태

- 관리자 문장 설정 화면에서 전체 문장을 조회하는 API만 존재했다.
- 실제 일상 영어와 코드 타자 연습 화면에서 유형별 연습 문장을 가져올 공용 API 함수가 없었다.

## 작업 내용

- `/typing/problems/practice`를 호출하는 `getProblemsForPractice` 함수를 추가했다.
- 함수가 전달받은 연습 유형을 `type` 쿼리 파라미터로 보내도록 구성했다.
- 응답 타입을 `TypingProblem[]`로 명시했다.
- entities 배럴 파일에서 연습용 조회 함수를 사용할 수 있도록 export했다.

## 결과

- 일상 영어, Java와 JavaScript 연습 화면이 동일한 함수로 유형별 문장 목록을 요청할 수 있다.
- 관리자용 전체 목록 조회와 사용자 연습용 유형별 조회의 역할이 분리된다.
- 호출부가 entities 공개 경로를 통해 타입이 지정된 조회 함수를 사용할 수 있다.
