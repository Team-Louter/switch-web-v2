# 타자 연습 문장 삭제 API 연결

## 사용자 프롬프트

문장 목록 조회, 추가, 수정, 삭제 API 연결을 각각 별도 커밋으로 나눈다.

## 기존 상태

- 문장 목록에서 삭제 버튼을 누르면 확인 모달은 표시되었지만, 최종 삭제 버튼은 모달을 닫기만 했다.
- 삭제 대상의 서버 식별자가 실제 요청에 사용되지 않았다.

## 작업 내용

- `/admin/typing/problems/{problemId}`에 DELETE 요청을 보내는 `deleteProblem` 함수를 추가했다.
- 삭제 확인 모달이 선택한 문장의 `problemId`로 삭제 요청을 보내도록 연결했다.
- 요청 중에는 삭제 버튼을 비활성화하여 같은 문장에 대한 중복 요청을 방지했다.
- 성공하면 문장 설정 목록으로 돌아가 서버 목록을 다시 조회하고, 실패하면 확인 모달을 유지하도록 했다.

## 결과

- 사용자가 확인한 문장이 서버에서 실제로 삭제된다.
- 삭제 완료 후 갱신된 목록이 표시되어 제거 결과를 즉시 확인할 수 있다.
- 요청 실패 시 대상과 확인 화면이 유지되어 동일 작업을 다시 시도할 수 있다.
