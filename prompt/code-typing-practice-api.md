# 코드 타자 연습 문장 API 연결

## 사용자 프롬프트

현재 개발한 변경을 코드와 파일 단위로 나누고, 코드 타자 연습 문장 API 연결을 별도 커밋으로 구성한다.

## 기존 상태

- Java와 JavaScript 연습 화면은 파일에 선언된 하나의 고정 코드 예시만 표시했다.
- 입력 에디터에도 기준 코드가 초기값으로 들어가 있어 사용자가 빈 상태에서 직접 입력하는 연습 흐름이 아니었다.
- 한 문제를 완료한 뒤 다음 문제로 전환하는 동작이 없었다.

## 작업 내용

- URL의 언어 값을 서버 문제 유형으로 변환해 Java 또는 JavaScript 연습 문장 목록을 조회하도록 연결했다.
- 고정 `CODE_LINES`를 제거하고 현재 문제의 본문을 줄 단위로 나누어 기준 에디터에 표시했다.
- 입력 에디터는 빈 값으로 시작하고 마운트 시 자동으로 포커스되도록 했다.
- 오답 장식, 타수와 정확도 계산이 현재 API 문장을 기준으로 동작하도록 변경했다.
- 현재 코드 길이만큼 입력한 뒤 Enter를 누르면 다음 문제로 이동하고 입력값을 초기화하도록 했다.
- 마지막 문제를 완료하면 타자 연습 진입 화면으로 이동하도록 했다.

## 결과

- 코드 연습 화면이 선택한 언어에 맞는 서버 문장을 순서대로 제공한다.
- 사용자는 빈 편집기에서 기준 코드를 직접 따라 입력하며 오답과 실시간 통계를 확인할 수 있다.
- 문제 완료 시 다음 코드로 전환되고 모든 문제를 마치면 연습 진입 화면으로 돌아간다.
