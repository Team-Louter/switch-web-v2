# 타자 연습 API 응답 타입 명시

## 사용자 프롬프트

현재 개발한 변경을 코드와 파일 단위로 나누고, 타자 연습 API 응답 타입 변경을 별도 커밋으로 구성한다.

## 기존 상태

- 관리자 문장 목록 조회 요청은 반환 타입이 명시되지 않아 API 클라이언트 응답 데이터의 구조가 호출부에 충분히 전달되지 않았다.
- 문장 추가와 수정 요청은 응답 본문을 사용하지 않지만 API 클라이언트 제네릭에 이를 표현하지 않았다.

## 작업 내용

- 관리자 문장 목록 조회에 `TypingProblem[]` 응답 타입을 명시했다.
- 문장 추가와 수정 요청에 `void` 응답 타입을 명시했다.
- API 경로, 요청 파라미터와 기존 호출 방식은 변경하지 않았다.

## 결과

- 문장 목록 응답이 `TypingProblem` 배열이라는 사실을 타입 검사 과정에서 확인할 수 있다.
- 추가와 수정 API가 응답 데이터를 사용하지 않는 요청임이 코드에 명확히 표현된다.
- 실행 동작을 바꾸지 않고 API 함수의 타입 안정성이 개선되었다.
