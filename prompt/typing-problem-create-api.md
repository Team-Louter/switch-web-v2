# 타자 연습 문장 추가 API 연결

## 사용자 프롬프트

문장 목록 조회, 추가, 수정, 삭제 API 연결을 각각 별도 커밋으로 나눈다.

## 기존 상태

- 문장 추가 편집기는 카테고리와 문장을 입력할 수 있었지만 제출하면 모달을 닫을 뿐 서버에 저장하지 않았다.
- 개발 언어 문장과 일상 영어 문장을 서버의 문제 유형 값으로 변환하는 제출 로직이 없었다.

## 작업 내용

- `/admin/typing/problems`에 `problemType`과 `content`를 전송하는 `createProblem` 함수를 추가했다.
- 일상 영어는 `DAILY`, 개발 언어는 선택값을 대문자로 변환한 `JAVA` 또는 `JAVASCRIPT`로 요청하도록 구성했다.
- 신규 문장 제출 중에는 중복 요청을 막기 위해 제출 버튼을 비활성화했다.
- 요청 성공 시 문장 설정 목록으로 돌아가 다시 조회된 목록을 확인하고, 실패 시에는 작성 내용을 유지하도록 했다.

## 결과

- 문장 추가 화면에서 작성한 내용이 서버에 저장된다.
- 저장 직후 문장 목록 화면으로 돌아가 추가된 데이터를 확인할 수 있다.
- 요청 도중 반복 클릭으로 동일한 문장이 중복 생성되는 가능성이 줄어든다.
